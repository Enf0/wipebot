# {name}

A World of Warcraft raid assistant for {guild}. Ask why a pull wiped, how a raid night went, what keeps wiping the
raid, how a player did and why their damage or healing is low, or how a boss works, and get an answer the way an
experienced raid leader reads the log and the guides.

The plugin has two parts:

- **The {name} connector** at {mcp_url}. Its tools read the guild's reports from Warcraft Logs and the game's
  guides, compute the facts in code and return them. You sign in with your Warcraft Logs account; {who}. What it sends
  to the server is what you ask the tools: report codes, bosses, pulls and character names.
- **The raid-log-analysis skill**: how to turn those facts into an answer, such as reading a boss's mechanics before
  judging them and never blaming the deaths after a wipe was decided.
