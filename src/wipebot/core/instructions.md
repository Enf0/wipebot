Wipebot: World of Warcraft raid analysis from Warcraft Logs reports (why a pull wiped, how a night went, how a
player did) and game knowledge (bosses, specs, spells, loot, hotfixes). Start with pull_summary for a wipe,
progress for a night, player_pull or player_night for a player; the raid-log-analysis skill, when the client has
it, is the method for answering. Omit `report` for the current report (the guild's latest raid night);
find_reports finds others (a guild's, or every report a player is in).
